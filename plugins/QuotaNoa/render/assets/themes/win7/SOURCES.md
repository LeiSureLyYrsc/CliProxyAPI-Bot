# Windows 7 (Aero Glass) Assets Source & License Documentation

This directory contains asset documentation and licenses for the `win7` theme in `QuotaNoa`.

## 1. Windows 7 Aero Glass Window Controls & Aesthetics
- **Source & Inspiration**: Inspired by the official Windows 7 Aero Glass visual language and design techniques from [7.css](https://github.com/khang-nd/7.css) (MIT License).
- **Implementation**: Fully recreated using pure CSS3 gradients, specular highlights, box-shadows, `@supports (backdrop-filter: blur(10px))` glass reflections, and authentic emerald green progress bars.
- **Strict Compliance**: Zero Microsoft proprietary binaries, DLLs (`shell32.dll`, `imageres.dll`, `aero.msstyles`), bitmap dumps, copyrighted fonts (Segoe UI is referenced in standard fallback lists only), or Microsoft logos/flags/Start Orbs are used. Abstract geometry is used for window titlebar icons.

## 2. Windows 7 Aurora Backdrop
- **Aurora / Harmony Backdrop**: 100% pure CSS multi-stop radial and linear gradients emulating the deep oceanic blue, cyan ribbons, luminous top-center glow, and subtle bottom reflection. Zero remote network requests or copyrighted wallpaper images.
