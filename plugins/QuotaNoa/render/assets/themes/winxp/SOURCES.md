# Windows XP (Luna) Assets Source & License Documentation

This directory contains lightweight asset documentation and licenses for the `winxp` theme in `QuotaNoa`.

## 1. XP Window Controls & Skeuomorphic Styling
- **Source**: Inspired by Windows XP Luna UI and minimal design techniques from [XP.css](https://github.com/botoxparty/XP.css) (MIT License).
- **Implementation**: Fully recreated using lightweight, sub-pixel accurate pure CSS3 gradients, box-shadows, SVG vectors, and CSS segmented progress bars. No heavy 250KB CSS bundle is imported.

## 2. Bliss Background & Icons
- **Bliss Backdrop**: 100% pure CSS multi-stop radial and linear gradients emulating the blue sky, fluffy clouds, and rolling green hills. Zero external requests, zero Microsoft copyrighted wallpapers or bitmap extracts.
- **Icons & Controls**: Rendered via pure CSS or standalone inline/embedded SVG vectors (CC0 / Public Domain inspired, zero Windows binary extractions such as `shell32.dll` or `imageres.dll`).
