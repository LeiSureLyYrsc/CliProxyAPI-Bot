# Default Theme (shadcn) Sources & References

This directory contains theme resources and metadata for the `default` theme in `QuotaNoa`.

## 1. Visual Style & Philosophy
- **Inspiration**: Design patterns inspired by [shadcn/ui](https://ui.shadcn.com/) (MIT License).
- **Implementation**: Pure modern CSS using zinc dark palette, subtle 1px translucent borders, and clean typography. Zero external JavaScript, fonts, or remote assets.
